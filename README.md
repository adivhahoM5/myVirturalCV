Adivhaho Mulaudzi — Portfolio

A personal portfolio website for Adivhaho Mulaudzi, a final-year BSc Information Technology student at North-West University specializing in backend development with C#, ASP.NET Core, and RESTful APIs.

Live layout: single-page site with a fixed sidebar navigation, smooth scrolling, and a dark, developer-console-inspired design.

Live site: https://adivhahoM5.github.io/myVirturalCV/

**Features**

 Hero section with a fixed API-console/terminal panel showing a sample GET /api/contacts request and JSON response, reflecting the site owner's REST API experience.

 Sidebar navigation with profile photo, resume download link, section links, and social links (LinkedIn, GitHub, Instagram).

 Sections: About Me, Projects, Skills, Education, Leadership & Involvement, Contact.

 Scroll-based interactions:

 Scroll progress bar at the top of the page.
 
 Sections and cards fade/slide into view as you scroll.

 Active nav link highlights based on which section is in view.

 "Back to top" button appears after scrolling down.

 Cursor glow effect that follows the mouse on desktop (disabled on touch devices).

 Copy-to-clipboard button next to the email address in the Contact section.
 
 Mobile-responsive: sidebar collapses into a toggleable menu on small screens.
